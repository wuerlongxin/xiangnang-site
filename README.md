# 湘知古香事 · 莲馨香囊宣传网站

Flask 后端 + 服务端渲染的宣传站：产品展示、四种香型、AI 定制香囊模块，响应式（PC / 手机），湖湘非遗配色（宣纸米白、湘绣朱红、黛青、金线）。

## 产品事实来源

- 产品介绍与图片：用户上传的 `1-2.docx`（香囊、香梳、线香、倒流香、香珠香串、打香篆、小盘香、大盘香、香牌），图片已从文档中提取到 `static/img/`。
- 价格只写计划书里有测算口径的：香囊香饰 168 元、香品 128 元起；其余产品不编价格，显示“即将发售”。
- 功效类表述统一为“香气氛围”描述，不作医疗、保健功效宣称；源头为山东潍坊莲馨香制作技艺·传习所（代表性传承人曹昭元），湖南推广，授权先行。

## AI 定制模块怎么工作

不是接外部大模型，而是一套写在 `generator.py` 里的“香型知识库 + 规则生成”：

1. 功用 → 对应传统合香香型（安神 / 固神 / 凝神 / 悦神，出自产品介绍文档）；
2. 使用场景 → 决定囊型、挂绳与使用方式（随身佩戴 / 挂床头 / 放车内 / 摆书房 / 送礼）；
3. 外包装风格 → 决定配色、纹样与寓意（荷花 / 菊花 / 梅花 / 兰花 / 柿子），并生成一幅 SVG 香囊示意图；
4. 香气浓度 → 决定香材配比倾向与留香参考。

香材只用文档里出现过的天然香材（艾叶、薄荷、丁香、佩兰、沉香、檀香、藿香），师傅的具体配方比例不公开、不上云。接口：`POST /api/generate`，入参 `{"function","scene","style","intensity"}`，返回方案 JSON（含 SVG）。

## 本地运行

```bash
cd xiangnang-site
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

打开 http://127.0.0.1:5000

## 结构

```
app.py                 Flask 入口：/、/api/options、/api/products、/api/generate
generator.py           AI 定制模块：选项、配色、纹样 SVG、生成逻辑
data.py                产品、香型、工艺数据（来自产品介绍文档）
templates/index.html   首页模板
static/css/style.css   湖湘非遗风格 + 响应式
static/js/app.js       AI 模块前端交互
static/img/            产品实拍图（来自 1-2.docx）
```

## 部署提示

这是一个 Flask 应用，不能直接放到 Cloudflare Pages 这类纯静态托管上。如需公开访问，可部署到支持 Python 的免费托管（如 Render / Railway / PythonAnywhere 的免费档），或在自己的服务器上用 gunicorn + 反向代理运行。部署前请先确认曹昭元 / 传习所的授权进展，授权未落实前不要以传承人名义对外销售。
